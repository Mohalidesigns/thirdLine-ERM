2. LISTENER CLASSES (7 FILES)
================================================================================

Location: /app/Listeners/

1. RecalculateResidualRisk.php
   - Triggered by: ControlUpdated
   - Action: Recalculates residual risk for all linked risks
   - Integration: Uses ControlEffectivenessService

2. EscalateRiskOnKriBreach.php
   - Triggered by: KriBreachDetected
   - Actions:
     * Updates risk_velocity to 'increasing'
     * Sets review_required = true
     * Schedules review for +7 days
     * Records audit trail entries
     * Creates domain_events for further processing

3. EvaluateRegulatoryThresholds.php
   - Triggered by: LossEventCreated, LossEventAmountChanged
   - Action: Evaluates loss against CBN/NFIU regulatory thresholds
   - Integration: Uses RegulatoryThresholdService

4. SendNotification.php
   - Triggered by: ALL events (implements ShouldQueue)
   - Action: Creates notification log entries with appropriate priority
   - Feature: Dynamic notification mapping based on event type
   - Database: Inserts into notifications_log table

5. UpdateRiskFromAssessment.php
   - Triggered by: AssessmentApproved
   - Action: Updates risk scores from assessment data
   - Integration: Uses RiskScoringService

6. TriggerRiskReassessment.php
   - Triggered by: TreatmentCompleted
   - Action: Applies treatment's expected risk reduction to residual score
   - Formula: residual_score * (1 - (expected_reduction / 100))

7. FlagRiskForReview.php
   - Triggered by: LossEventCreated
   - Logic: Flags risk if 3+ loss events recorded in 12 months
   - Purpose: Mandatory review trigger

9. WORKFLOW EXAMPLES
================================================================================

CONTROL UPDATE WORKFLOW:
  Control.update() → ControlUpdated event → RecalculateResidualRisk → 
  Risk scores updated → SendNotification → Notification log created

KRI BREACH WORKFLOW:
  CheckKriBreaches command → Compare measurements → KriBreachDetected event →
  EscalateRiskOnKriBreach (flag risks, update velocity) → SendNotification →
  Notifications created with critical/high priority

LOSS EVENT WORKFLOW:
  LossEvent.create() → LossEventCreated event → EvaluateRegulatoryThresholds →
  Check regulatory thresholds → FlagRiskForReview → SendNotification

TREATMENT COMPLETION WORKFLOW:
  Treatment.markComplete() → TreatmentCompleted event → TriggerRiskReassessment →
  Apply risk reduction → Update residual score → SendNotification

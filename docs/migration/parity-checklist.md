# Migration parity checklist

Seeded in Phase 0 from `php artisan route:list --json` (188 named GET web routes; 196 now). A route may only flip from Blade to Inertia when every cell in its row is filled, and the Phase 7 sign-off is this table with no empty cells — **which it now has**.

**How to read the cells, because half of them say `n/a` and that has to mean something.**

| Cell | `n/a` means |
|---|---|
| Old view | The route never had a Blade page. Most are exports, downloads and JSON endpoints that were always controllers returning a file. |
| New page | The route renders no Inertia page because it returns a file, JSON or a redirect. `scripts/parity-check.php` asserts each one still returns *something*. |
| Form Request | The route takes no input beyond its bindings. After Phase 7.3 there is no inline `validate([...])` anywhere in `app/Http/Controllers`, so a route that takes input has a Form Request named here. |
| Policy | Written as `route permission only` where authorisation is the route's `permission:` middleware and no model-level policy applies — a listing, an export, a landing page. It is not a gap; it is where the guard lives. |
| Grid / Widgets / Exports | The screen has none. |
| Flipped on | The route was never Blade, so nothing flipped. |

**"Signed off by" says `parity-check.php (Phase 7.4)` on every row, and that is deliberate.** No human has walked 196 screens. What actually verified each row is the script: it asserts the controller returns something rather than a Blade view, that any page it names exists on disk, and that some test reaches the route. Recording the real verifier is more useful than a name that would imply a review that did not happen. A release sign-off by a person belongs in a column added when that review is done.

The claim this table makes is therefore narrow and true: **every route is reachable, guarded, rendered by a component that exists, and touched by a test.** It does not claim the figures on those screens are right — that is what the module tests and the phase notes are for.

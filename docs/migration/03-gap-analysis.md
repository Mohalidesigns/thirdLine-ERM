# 03 — Gap analysis: `risk copy/` vs `internalaudit/`

Effort: **S** ≤ 2 engineer-days, **M** 3–8, **L** > 8. Risk: likelihood × impact of the change breaking something that works today. "Reuse" = keep as-is; "Refactor" = keep the code, change its shape/callers; "Rebuild" = write again in the target pattern.

## 2. Classification summary

**Reuse as-is (no change or trivial):** all 105 tables and 92 models; tenancy kernel; `GraphScope`; `CheckPermission` + routes + `RouteAuthorizationTest`; all 100 services (`Workflow/`, `Widgets/`, `Scoring/`, `Configuration/`, `Graph/`, `Integrations/`, `Mcp/`, `Webhooks/`, `Metadata/`); `app/Grids/GridDefinition` + 22 definitions; API/SCIM/SSO/webhooks/connectors/MCP; jobs, commands, scheduler; `reports/pdf/**` Blade templates and `emails/**`; the test suite. From ThirdLine: `resources/css/app.css`, `Components/*`, `Layouts/*`, `utils.js`, `lib/richtext.js`, `lib/navScope.js`, `app/Services/Licensing/*`, licence middleware/config/page, `App\Casts\RichText*`, `Services/RichText/*`, `SetSecurityHeaders`, `LogRequestActivity`.

**Refactor:** controller return types (`view()` → `Inertia::render()`); fat controllers → services (5 extractions); nav → data; bell → shared prop; `DataGrid` server side → `GridPresenter`; `FormFieldRegistry` → JSON schema for React; `charts.js` → React hooks; CI; `vite.config.js`.

**Rebuild:** every screen as a React page (~180 pages from 211 views, minus 15 PDF + 1 email + 4 pagination + 9 components); 11 Livewire components as React (grid, dynamic form, 6 builders, dashboard builder/panel, job progress); auth pages; Form Requests + Policies across all modules; `HandleInertiaRequests`.

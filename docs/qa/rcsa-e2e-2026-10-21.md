## Item 8 — "fortnightly" was not flagged (investigated, not changed)

**What happens.** `RcsaImportNormaliser` maps Control Frequency onto
`RcsaRegisterControl::FREQUENCIES` (`continuous, daily, weekly, monthly,
quarterly, annually, ad_hoc`) through `canonical()`. An unrecognised value
becomes `null` **silently**: it adds no note, so the validator raises nothing.
Control Type is handled the same way.

**On the row in the E2E (no Existing Control): the outcome is correct.** The
publisher builds a control only from a non-blank Existing Control
(`RcsaImportPublisher::controlsFrom`), so a frequency on a control-less row has
nothing to attach to. That row already carries the warning "No existing
control. The assessment will have nothing to rate for this risk." Any further
warning about the frequency would describe a value that is discarded either
way.

**The general case is a gap.** The same silent drop happens on a row that
**does** name a control. "Fortnightly" next to a real control publishes as a
control with no frequency, and the preview shows no warning. The fix is a
normalisation note (a warning, never an error, matching how an unresolved
Control Owner is handled): "'fortnightly' is not a recognised frequency, so the
control will have none." Raise it only when Existing Control is filled. This is
left as a follow-up, because the brief for this batch was "investigate only".

## Product decisions — not changed, for the owner

- **(a)** Closing a cycle stamps every assessment "Closed", including ones still
  submitted, under review or escalated, exactly as it stamps validated ones.
  The close confirmation does not mention those. Should a close be refused
  while any are mid-review, or should the dialog name them?
- **(b)** Validate is allowed while risks are still "not looked at", and
  without "Start review". Should validation require every line to be accepted
  or challenged first?
- **(c)** The workspace's "Last cycle" column shows the prior **inherent**
  score, while dashboard movement compares **residuals**. Which one should the
  workspace show?
